# Competency catalog provenance

KlasePH distinguishes official curriculum entries from teacher-provided text.

- Only a super administrator can import entries marked `is_official`.
- Official imports require an HTTPS source under `deped.gov.ph` and a human-readable source version.
- Exams snapshot the competency text, source URL, and source version used when they are published. Later catalog changes do not rewrite historical assessments.
- Text entered directly by teachers remains `Teacher provided` unless it matches a reviewed catalog entry. A URL alone does not automatically make an entry official.

The primary curriculum landing page currently used for provenance is:

- https://www.deped.gov.ph/matatagcurriculumk147/

DepEd distributes curriculum guides as documents rather than through a stable public competency API. Catalog ingestion therefore remains an explicit, reviewed administrative operation.
